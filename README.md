# Julian Grossman Portfolio

A personal portfolio for Julian Grossman, built with React, vinext, Material 3 design tokens, and an interactive Spline scene.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
npm test
```

The résumé is rebuilt from `scripts/build_resume.py` and published from `public/Julian_Grossman_Resume_2026.pdf`.
